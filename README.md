# Tag Studio — tag.wfrz.eu

MC chat tag generator. Solid / gradient / rainbow farby, štýly (bold,
italic, underline, strike, magic), zátvorky. Live preview a 1:1
kompatibilný výstup s tag pluginom (`&` codes, `<gradient>`, `<rainbow>`,
`{#a>}...{#b<}` bracket syntax).

Použitie:
1. Napíš text + vyber farbu / štýl / zátvorky
2. Skopíruj vygenerovaný reťazec
3. V hre: `/tag shop` → Vytvoriť vlastný tag → vlož do chatu
